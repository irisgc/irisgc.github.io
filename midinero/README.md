# Mis Finanzas

App para organizar ingresos, gastos fijos, suscripciones y ahorro mes a mes.

- Se instala en el móvil desde el navegador («Añadir a pantalla de inicio»).
- No necesita cuenta.
- **Los datos de cada persona se guardan solo en su propio móvil.** La app no envía nada a ningún servidor; este repositorio solo contiene el código.
